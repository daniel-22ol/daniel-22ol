## 📌 Sobre Mim

Sou graduando em **Engenharia de Software** pela **Universidade Católica de Brasília (UCB)**. Tenho um perfil focado no desenvolvimento de sistemas sólidos, utilizando arquiteturas em C e explorando o desenvolvimento no ecossistema Apple com Swift.

- 💻 **Foco:** Sistemas de gestão, cálculos e lógica de baixo e alto nível.
- ⚙️ **Ambientes:** Fluxo de trabalho transitando fluidamente entre **Apple macOS** e **Windows**.
- 🚀 **Momento Atual:** Construindo projetos acadêmicos robustos e expandindo para soluções financeiras pessoais.
